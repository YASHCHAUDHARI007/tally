# **App Name**: TallySync Pro

## Core Features:

- Employee Login: Secure, role-based access control for different employee levels (Admin, Sales, Store).
- Barcode Scanning: Scan barcodes using the device camera or a USB scanner. Fetch item details from Tally Prime via the XML API using the barcode as the lookup key.
- Stock Dashboard: Display real-time stock levels fetched from Tally Prime via XML API. Allows filtering and searching by item, category or warehouse.
- Receipt/Invoice Generation: Create receipts and invoices within the app and automatically create vouchers in Tally Prime through the XML API. Data is auto-fetched from Tally to minimize input.
- Activity Logging: Log all user activities, including scans, voucher creation, and logins, to maintain an audit trail. Retain the user id, timestamp, and relevant data IDs.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and reliability, reflecting the importance of financial data.
- Background color: Very light gray (#F5F5F5), a desaturated version of the primary hue for a clean, professional backdrop.
- Accent color: A slightly muted purple (#7E57C2), approximately 30 degrees from the primary, adding sophistication.
- Body and headline font: 'Inter', a grotesque-style sans-serif providing a modern, neutral, machined look that suits data-heavy interfaces.
- Use simple, geometric icons to represent different categories and actions, aligning with the app's professional and efficient tone.
- Maintain a clean, grid-based layout with sufficient whitespace to ensure readability and focus on key data elements.
- Use subtle animations for data updates and transitions to provide visual feedback without being distracting.
